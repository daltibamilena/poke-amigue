# PokeAmigue

This project is a lightweight monorepo with:

- NestJS backend in `apps/api`
- React + Vite frontend in `apps/web`

## Quick start

```bash
npm install
npm run dev:api
npm run dev:web
```

The API runs on `http://localhost:3000` and the frontend runs on `http://localhost:5173`.

## Production build

```bash
npm run build
```
